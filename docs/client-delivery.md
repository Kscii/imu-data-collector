# 客户数据交付与只读查看

## 交付单位

每个客户交付包严格绑定一个不可变训练快照 `snapshot_id`。训练快照生成后，平台可在后台生成
一个 ZIP64 文件；生成过程不阻塞标注和其他快照操作。相同快照只生成同一份内容，旧版、缺少
冻结视频映射的历史快照不会被静默升级，必须从当前已完成录制重新生成快照。

交付 ZIP 包含：

- `dataset/cw12eu.h5`：严格 25 Hz、六轴 SI 单位的合并训练数据，HDF5 schema 3.1.0；
- `recordings/<recording_id>/video.mp4`：该录制用于复核的原始可识别视频；
- `recordings/<recording_id>/view.json`：该录制样本、标注和视频媒体时间的冻结映射；
- `manifest.json`：快照身份、数据合同、录制列表及文件清单；
- `README.md`：面向接收方的简短使用说明；
- `SHA256SUMS`：包内主要文件的 SHA-256。

视频不嵌入 HDF5。这样不会修改训练合同，也避免每个训练工具都必须理解视频编解码。交付时应
整体传递 ZIP，而不是单独传递其中某个文件；接收方可用 `SHA256SUMS` 和 `manifest.json`
确认完整性与来源。

## 在线查看

“训练快照”页面提供仅限团队白名单账号使用的只读查看入口。查看器读取快照冻结的合并 H5、
视频对象和 `view.json`，不读取之后可能被重开或修改的当前 review。因此历史快照的画面、曲线
和标注不会随工作区状态漂移。查看器不能修改标注，也不是对客户公开的分享链接。

## 时间轴显示

标注页完整录制总览使用分桶的逐轴极值保留抽样，避免长录制中的短时峰值被普通等步长抽样
漏掉。默认仍显示完整六轴曲线；展开“局部”后，在同一个固定高度区域内显示紧凑总览，以及
当前游标附近 2、5 或 10 秒的加速度和角速度原始点。拖选完整总览会打开局部视图并选择最接近
的窗口预设。

## 隐私边界

客户交付包包含可识别参与者的视频，只能在已有参与者同意和交付授权范围内生成、保存和传输。
在线查看继续受平台 Google/IAP 白名单保护；ZIP 下载后由交付方负责使用受控渠道和约定的保留
期限。
