# IMU—视频同步验证协议

## 验证目标

判断 CW12EU-T 与罗技摄像头在当前 Arch 主机上的最佳时间对齐方法。需要比较：

1. 直接使用主机重建的 IMU 时间；
2. 跨录制共用一个固定偏移；
3. 每条录制单独校正常数偏移；
4. 每条录制拟合 `video_time = scale × imu_time + offset`。

实验只记录事实与误差，不提前把任何候选写入正式 H5 同步模型。

## 为什么仍要轻拍

电脑在 Bleak 回调中记录的是整包 BLE 通知的到达时间。当前一个 400-byte 通知包含 25 个
16-byte 候选样本，因此回包时间不是每个传感器样本的真实采样时刻。平台用全部包到达时间
拟合样本间隔，但设备缓存、BLE 和 BlueZ 的总体延迟仍可能形成未知偏移。

视频帧 PTS 与 BLE 回调虽然都映射到 Linux 单调时钟，打时间戳的位置却不同。轻拍外壳能在
视频和 IMU 中产生同一个可观察事件，用于测量两条管线的实际差值。

## 设备摆放

- 该实验不执行跌倒，也不属于正式动作数据。
- IMU 稳定放在不会摇晃的平面或夹具上，外壳与手均完整入镜。
- 不按功能键，只用手指轻拍外壳；每次轻拍之间保持足够间隔。
- 使用 WebUI 选择罗技外接彩色摄像头，数据级别固定为 `test`。
- 批次 ID 使用 `sync_validation_01`，参与者使用 `xfan0282`。

## 录制矩阵

### 五次独立短录制

- 每条约 90 秒。
- 约在 10、25、45、65、80 秒各轻拍一次，共 5 次。
- 每条停止并完成收尾后，释放预览设备，再重新连接后开始下一条。
- 目的：测量重新连接和重新启动 FFmpeg 后，绝对偏移是否重复。

### 一次长录制

- 总长约 10 分钟。
- 约在 10、120、240、360、480、590 秒轻拍，共 6 次。
- 目的：测量同一连接内的时钟漂移。

整个实验应产生 6 条 test 录制和 31 个轻拍观察。

## 浏览器逐帧复核

1. 启动服务后打开 `http://127.0.0.1:8765`。
2. 进入“标注”，选择 `sync_validation_01` 中的一条录制。
3. 播放到轻拍附近并暂停。
4. 使用“上一帧/下一帧”或键盘 `←/→`、`,`/`.` 逐帧移动。
5. 选择手首次接触外壳的帧，不选择手尚未接触或接触后的最大形变帧。
6. 点击“此帧是手接触时刻”。页面加载该帧附近 ±1.5 秒的完整 IMU 原始六轴数据。
7. 页面会自动预选一个 IMU 代表样本：优先使用本条录制已有观察拟合线性漂移；只有一个
   观察时使用固定偏移；本条尚无观察时使用已有录制的全局偏移。预测位置附近必须实际存在
   显著冲击，否则不会仅凭时间模型生成候选。
8. 人工检查自动推荐、置信度和附近曲线。高置信度也必须点击“确认并保存观察”；中低置信度
   应逐个比较候选，必要时改选。程序不会自动保存。
9. 确认轻拍编号并保存实验观察。
10. 不展开或保存“正式 IMU—视频同步模型”。

实验 JSON 位于：

```text
~/IMUData/_diagnostics/sync_validation_01/
  sync_validation_01.sync-experiment.json
```

它保存视频帧号/PTS、IMU 样本号/主机重建时间、复核者、原始文件路径、大小和 SHA-256，
并记录候选算法、推荐样本、置信度、候选强度排名、评分和当时使用的偏移。这样可以区分
“接受自动推荐”和“人工改选”，也能在算法升级后审计旧观察。原始 H5 与 MKV 不会被修改。

## 生成报告

```bash
cd /home/kscii/Codes/imu-data-collector
uv run imu-collector analyze-sync-experiment \
  ~/IMUData/_diagnostics/sync_validation_01/sync_validation_01.sync-experiment.json
```

输出同目录的机器可读 JSON 和中文 Markdown 报告。报告采用留一录制或留一锚点误差，避免
用参与拟合的点本身产生虚假的零误差。

## 参考尺度与停止条件

- 30 FPS 一帧约 33.333 ms。
- 首轮参考为中位绝对误差不超过一帧、P95 不超过两帧。
- 该标准只说明是否适合 30 Hz 级时间网格，不代表毫秒级地面真值。
- 若某个轻拍无法唯一对应，先重新复核，不强行保存。
- 若所有候选方法都超出参考范围，停止冻结正式同步格式，继续调查 BLE 批量延迟、样本重建
  和 trailer。
- trailer 即使表现得像计数器，也必须有跨录制一致证据和独立验证后才能用于正式时间轴。
