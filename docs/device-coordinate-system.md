# CW12EU-T 坐标系与工程校准档案

## 适用范围

本文只适用于 BLE 地址 `83:FC:90:14:1E:A4` 对应的当前 CW12EU-T 实物。即使另一个设备
外观和型号相同，也必须至少复做六面静止与三轴旋转检查，不能直接继承本档案。原始 BLE
payload 与六轴计数始终保留；校准档案只决定如何生成可重建的 SI 派生值。

当前档案 ID 为 `cw12eu_t_83fc90141ea4_v1_20260827`，状态为
`engineering_verified`。它表示六面静止和多轴手工 360° 旋转之间没有发现方向冲突，足以
支持本项目的工程换算与训练前处理；它不是计量实验室可溯源校准，也不能证明 MEMS 型号。

## 目标坐标系

平台使用右手坐标系，语义固定如下：

| 目标方向 | 设备外壳方向 | 对应朝上时的重力符号 |
|---|---|---|
| `+X` | 佩戴者右侧；接口面的反面 | 接口面朝下时约 `+1 g` |
| `-X` | 接口面 | 接口面朝上时约 `-1 g` |
| `+Y` | 头部方向；吊坠/挂绳端 | 吊坠面朝上时约 `+1 g` |
| `-Y` | 吊坠面的反面 | 吊坠面朝下时约 `-1 g` |
| `+Z` | 身体外侧；按键面 | 按键面朝上时约 `+1 g` |
| `-Z` | 身体内侧；充电口面/按键背面 | 按键面朝下时约 `-1 g` |

目标三轴相对原始三列的映射为：

```text
target_x =  raw_1
target_y = -raw_2
target_z =  raw_3
```

加速度计和陀螺仪使用同一列顺序与符号变换。这里的“顺时针”必须同时给出观察方向才能
确定正负，因此证据页面优先展示“主要响应轴和翻面后是否反号”，不把含糊的手工旋转名称
当作右手正方向的唯一依据。

## 换算参数与公式

当前原始空间零偏和比例为：

```text
accel_bias_counts_raw = [30, 48, -40]
gyro_bias_counts_raw  = [-17, 0, 10]
accel_counts_per_g    = 4096
gyro_counts_per_dps   = 32.8
axis_signs            = [1, -1, 1]
```

先在原始列空间减去零偏，再应用列顺序和符号：

```text
corrected_target = (raw - bias_raw)[raw_axis_order] * axis_signs
acceleration_mps2 = corrected_target_accel / 4096 * 9.80665
angular_velocity_rad_s = corrected_target_gyro / 32.8 * pi / 180
```

HDF5 的 `imu/samples/raw_counts` 不受上述公式影响；`imu/samples/values_si` 才使用冻结在该
条录制 H5 属性中的 profile、零偏、轴映射和比例。这样即使未来得到更好的校准，也可以从
原始计数重建新版派生数据，而不会覆盖旧证据。

## 证据与一致性

机器可读登记表位于 [calibration-evidence.yaml](../configs/calibration-evidence.yaml)。当前纳入：

- 六条相反外壳面的静止记录，分别验证 X/Y/Z 主响应列、符号、零偏和约 4096 counts/g；
- 八条绕三个几何轴的约 360° 手工旋转，验证陀螺仪主响应列、翻面反号与
  32.8 counts/(°/s) 的工程合理性；
- 一条短时自由落体，检查加速度模长下降和随后冲击是否符合物理预期。

六面静止的三轴半跨度约为 4086、4089 和 4089 counts/g。八条旋转按
32.8 counts/(°/s) 积分约 354.5°–370.6°，没有出现主响应轴或翻面符号冲突。手工旋转本身
存在起止、非纯轴和角度误差，因此不适合反推出更多有效数字；当前采用芯片常见且与全部实测
一致的 4096 和 32.8。

公网标注端的“设备校准证据”页按登记表只读展示这些录制，可播放原视频、复制录制 ID 并
下载原始 H5。校准证据不进入普通标注队列，也不因为它已验证设备比例就自动成为训练样本。

## 重新校准或升级档案

以下任一情况必须创建新的 profile ID，而不是静默修改当前参数：

- 更换实物、固件、外壳装配或佩戴方向；
- 复测发现轴映射、符号或比例冲突；
- 使用转台、已知角速度或可溯源仪器得到更高等级结果；
- 零偏或尺度随温度、时间出现超过项目容许范围的变化。

新录制会把所用 profile 和证据文件 SHA-256 冻结到 H5；旧录制继续保留当时档案，训练构建
时可以显式选择是否按新版 profile 从原始计数重新派生。
