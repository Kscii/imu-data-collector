# 动捕时间区间审核试验

## 当前：第三轮区间语义审核

新任务 `primary-semantic-pilot-20261008` 使用 run v3、annotation v2，仍为正式 HDF5 3.3
及相同的 24 类主活动。前 40 段为开发集，后 20 段是排除所有旧训练、校准和试验来源组
后的独立验证集。第二轮任务及其全部审核历史保留。

入口：`http://127.0.0.1:8770/?view=synthetic&temporal_run=primary-semantic-pilot-20261008&lang=zh-CN`。

每个区间可以独立填写自己的动作语义和多条备注，不要求语义文本匹配标签列表。
- **待讨论**：选择“如何归类／如何切分／词表未覆盖”等原因，可保留标签建议，但暂不训练。
- **已确认**：明确确认主活动和时间边界；录制质量通过后，该部分才进入训练或导出。
- **明确排除**：填写原因，原始数据与语义仍保留。未知不再自动等于永久废弃。

「保存区间草稿」只保存工作进度；「提交已确认区间」才写人工通过。同一录制可以只确认
其中一部分。后续保存新草稿会使旧通过暂时失效，需再次提交才用于新的训练或快照请求。
服务器按父草稿 SHA 检查并发冲突；冲突时保留本地编辑，可下载当前草稿。

相邻同类已确认区间保存时合并；不同备注不会强行制造动作边界。切分与合并保留备注
原时间范围；不同跌倒事件仍分开。备注进入 annotation 文档，因此参考冻结和正式 H5
都能保留。辅助标签本轮不编辑。

验证段可先存草稿，模型保持隐藏。所有区间确认或明确排除后才可冻结独立参考。
参考始终不训练；报告仅统计可评估的已确认时间。40 段旧数据迁移为待复核草稿，
没有自动写入新人工通过。前两段按讨论给出功能阶段建议，切点待确认；翻滚不直接认作跌倒。

Ubuntu 根目录：`~/.local/share/imu-motion-simulator/studies/primary-semantic-pilot-20261008/`。
其 `RUNBOOK.md` 记录预览、worker、端口转发和暂停方法；本轮不写云端、不替换生产模型。
训练按钮仍使用同一 TCN 配方，等待新开发区间的实际人工确认后再显式启动。

## 保留的第一轮试验

新增入口位于「合成运动 → 自动区间标注试验」，复用原 3D 回放和 IMU 图。
用户检查主活动、一个可选辅助动作及时间区间；普通任务只支持通过、退回和质量排除。
退回可指出错误区间及原因，最多自动重试两次，之后的排除建议仍需人工确认。

30 段试验中，12 段先填写独立参考，再显示模型草稿；参考不可被模型结果覆盖。
其中 4 段用于调整、8 段用于验证。参考编辑草稿暂存在浏览器，保存后写入不可变参考记录。
已有生产候选的审核指针不被本试验替换。

正式输出使用 HDF5 3.3：主辅区间、未识别原因和审核依据随同一 H5 保存。
辅助未知不会抹去已识别主活动；无法识别的主活动不作为负样本进入训练。
主辅拆分不会把同一个跌倒重复计数。

`GET/POST /api/v1/synthetic/temporal/runs` 管理隔离任务。每个任务提供 cases、reference、
review、report、snapshots 和 approve 接口。参考和通过/退回记录使用当前可信登录身份。
模型草稿、来源 commit、输入文件和上一条审核哈希都要匹配，过期写入返回冲突。
快照下载有任务归属检查，并复用既有 Range 下载接口。

全量开关要求 30 段审核完成、12 段独立参考和与参考哈希绑定的报告；人工另行选择辅助标签模式。
全量快照还检查所有当前来源候选已有人工质量结论。用户确认报告不会伪造任何单段通过记录。
